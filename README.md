# ChatGPT Usage Widget

Windows 11 floating widget for ChatGPT/Codex 5-hour and weekly usage limits.

## 0.3.0 UI/UX redesign

- resize directly by dragging any edge or corner
- independent width and height, remembered between launches
- responsive layouts that fit text inside the available space
- redesigned Dashboard, Cards, Compact strip, Rings and Gauges modes
- new custom dark Settings window with Appearance, Content and Behavior tabs
- reset to recommended size for each layout
- Windows CI validates source hash, builds, runs logic tests, publishes a self-contained x64 executable and performs WPF startup/render smoke tests

The release artifact is produced only after the Windows CI pipeline succeeds.
